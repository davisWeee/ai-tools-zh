三步上手

  1. Windows：下载官方仓库源码包，解压后双击 OneKeyStart.bat，首次运行会自动安装 uv、Python、依赖与 FFmpeg（需联网）。也可用 Docker 部署。
  2. 浏览器打开 Streamlit 页面，在侧边栏填写大模型 API 与语音识别、目标语言等设置。
  3. 上传或粘贴视频链接，一键运行，得到字幕（及可选配音）视频。
