三步上手

  1. 到官方 Releases 下载对应系统安装包（Windows .exe、macOS .dmg、Linux AppImage/.deb）并安装。
  2. 在软件内选择语音识别模型，并在翻译设置里选择翻译服务、填写 API 信息。
  3. 拖入视频，选择源语言与目标语言，开始处理，导出字幕文件或烧录进视频。
