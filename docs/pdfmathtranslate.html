三步上手

  1. 到官方 Releases 下载 Windows 压缩包（如 pdf2zh-v1.9.11-win64.zip）解压；或安装 Python 3.11–3.12 后执行 pip install pdf2zh。
  2. 运行 pdf2zh -i 打开网页界面（默认 7860 端口），上传 PDF。
  3. 选择翻译服务并填写所需 API Key（用免费服务则无需），点击翻译，得到中英双语 PDF。
